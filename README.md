# 결정의 시대 (Age of Decision)

> 제작·수집 방치형 RPG · 플레이 가능한 프로토타입
>
> **▶ 지금 바로 플레이: https://ggonggee.github.io/hwasin-play/**

대장장이/불의 신 컨셉의 다크 판타지 방치형 RPG. 방치로 재료를 모으고, **제작·강화라는 플레이어의 선택**으로 성장하는 구조가 코어다. 시장의 유사작을 벤치마크해 뼈대를 세웠고, 콘텐츠·명칭·아트는 전부 오리지널로 재조립했다.

## 이 저장소가 개발 원본이자 배포본이다

이 저장소는 **개발 저장소이면서 동시에 GitHub Pages 배포본**이다. 별도의 배포용 복사본은 없다.
`main` 에 푸시하면 그대로 라이브에 반영된다. 즉 **푸시 = 배포**다.

> 구 개발 저장소 `20260804_ZcodeHwasin` 은 v5.111 시점에 이 저장소로 일원화됐다.
> 내부 문서(`docs/` — 기획서·리서치·레퍼런스)와 Unity 아이콘 원본 팩은 용량·비공개 사유로 그쪽에 남아 있다.

빌드 도구·의존성이 **하나도 없다.** Node 는 검증 스크립트용이고, 게임 자체는 브라우저만 있으면 돈다.

```bash
npm run dev
```

`http://localhost:8765` 로 열린다. (Python 3만 있으면 된다. 없으면 아무 정적 서버나 이 폴더를 서빙하면 동일하다.)

세로 화면 게임이다. 브라우저 개발자도구에서 **모바일 뷰 375×812** 로 보는 걸 권장한다.

## 개발할 때 반드시 지킬 것

### 1. 편집 대상은 3개뿐

`index.html` · `style.css` · `game.js`. 단일 파일 미러(`화신.html`)와 `npm run build` 는 **v5.82 에서 폐기**됐다.

### 2. 커밋 전 전체 검사

```bash
npm run check
```

문법 → 정적 무결성 → 런타임 스모크. 셋 다 통과해야 한다. 실패한 채로 커밋하지 마라.

### 3. 배포는 검사를 통과한 뒤에

```bash
npm run deploy
```

`npm run check` 를 먼저 돌리고, 통과할 때만 `git push origin main` 한다. 푸시하면 1~2분 뒤 라이브에 반영된다.
푸시 전에 `git fetch` 로 원격이 앞서 있지 않은지 확인하는 습관을 들여라(다른 데서 올린 커밋과 갈라진 적이 있다).

### 4. 버전은 `npm run bump` 로 올린다

```bash
npm run bump 5.131
```

`package.json` 이 버전의 정본이고, `index.html` 의 캐시버스터(`style.css?v=` / `game.js?v=`)와
화면 표기는 여기서 파생된다. 손으로 맞추지 마라 — 어긋나 있으면 `npm run check` 가 [J] 에서 막는다.
(캐시버스터를 빼먹어 이용자가 옛 CSS 를 계속 받은 사고가 있어 게이트로 세웠다.)

### 4-1. 클론 직후 한 번 `npm run setup`

push 전 검사 훅(`.githooks/pre-push`)을 설치한다. 안 하면 `git push` 가 검사를 건너뛴다
— 즉 검사하지 않은 것이 그대로 라이브에 나간다.

### 4-2. 다른 폴더의 사본을 복사해 오지 마라

`v2` 작업본이나 구 저장소의 파일을 가져와 덮으면 그 사이의 수정이 통째로 사라진다.
2026-09-07 에 `style.css` 가 그렇게 3주 전 상태로 되돌아간 채 배포됐다. 항상 이 저장소의 현재 파일을 고쳐라.

### 5. 타사 IP 절대 금지

벤치마크에서 가져오는 것은 **구조·개수·수치·배치**뿐이다. 명칭·캐릭터명·고유 표현은 **전부 오리지널로 치환**한다. 과거에 리네이밍 표를 기계적으로 만들다가 다른 회사 IP와 충돌하는 이름을 만들어낸 사고가 있었다(상세: `HANDOFF.md`).
